# Punktefeld Multiplikation

> **[>>Hier geht es zum Punktefeld<<](www.test.de)**

Eine Web-App zum Üben von Multiplikation. Die Schüler:innen ziehen einen L-förmigen *Malwinkel* über ein Punktefeld, wählen so ein Rechteck aus Punkten aus und lösen Multiplikationsaufgaben mit unterschiedlichen Methoden.

## Funktionen

- **100er Feld** (10×10) und **400er Feld** (20×20).
- Malwinkel mit Finger oder Maus ziehen, um `Zeilen × Spalten` festzulegen.
- Aufgabenarten:
  - **Aufgabe** — Nur die Aufgabe wird angezeigt.
  - **Gruppen** — Auswahl als `Zeilen` Gruppen mit je `Spalten` lesen.
  - **Kernaufgaben** (100er) — Zerlegung in einfache Aufgaben (·1, ·2, ·5, ·10).
  - **Teilaufgaben** (400er) — Auswahl an den Quadrantengrenzen aufteilen.
  - **Malkreuz** (400er) — Malkreuz in zwei Phasen (zuerst Überschriften, dann Tabelle).
- Nach zwei verschiedenen falschen Eingaben wird die richtige Lösung angezeigt.
